# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✓         |

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email: security@bvasilenko.dev

Include: affected version, reproduction steps, impact assessment. Expect an acknowledgement within 72 hours and a resolution timeline within 14 days for confirmed issues.
